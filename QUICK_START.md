# ⚡ Démarrage Rapide - MemIA PWA

## 🚀 En 3 étapes

### 1️⃣ Installer les dépendances

```bash
npm install
```

### 2️⃣ Lancer l'application

```bash
npm start
```

### 3️⃣ C'est tout ! 🎉

Votre navigateur s'ouvrira automatiquement sur `http://localhost:8080`

---

## 📱 Alternative sans Node.js

### Avec Python 3

```bash
python3 -m http.server 8080
```

Puis ouvrez : `http://localhost:8080`

---

## ✅ Vérifier que tout fonctionne

1. ✅ La page s'affiche correctement
2. ✅ Ouvrez les DevTools (F12) → Console
3. ✅ Vous devriez voir : "Service Worker enregistré"
4. ✅ Testez l'enregistrement audio/vidéo (autorisez les permissions)
